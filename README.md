# 📰 Tech News

Tech News é uma página web de notícias sobre tecnologia, desenvolvida para praticar a criação de interfaces modernas utilizando HTML e CSS.

A interface apresenta diferentes categorias de tecnologia e uma organização em formato de portal de notícias, com uma notícia principal em destaque e outras notícias distribuídas em cards.

## ✨ Preview

O projeto apresenta:

- 📰 Notícia principal em destaque
- 🗂️ Categorias de tecnologia
- 🤖 Inteligência Artificial
- ⛓️ Blockchain
- 🌐 Internet
- 👕 Vestíveis
- 🥽 Realidade Virtual
- 🪄 Hologramas
- 📱 Design responsivo
- 🔎 Área de pesquisa
- ☰ Menu de navegação

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Design responsivo

## 🎯 Objetivo

Este projeto foi desenvolvido como parte dos meus estudos de desenvolvimento web, com o objetivo de praticar:

- Estruturação de páginas com HTML semântico
- Criação de layouts utilizando CSS Grid e Flexbox
- Organização de conteúdo em cards
- Hierarquia visual
- Responsividade
- Posicionamento de textos sobre imagens
- Criação de interfaces inspiradas em portais de notícias

## 🖥️ Estrutura da interface

### Header

O cabeçalho contém:

- Menu de navegação
- Nome do portal
- Campo de busca

### Categorias

A navegação secundária permite explorar diferentes áreas da tecnologia:

- Inteligência Artificial
- Blockchain
- Hologramas
- Internet
- Vestíveis
- Realidade Aumentada
- Realidade Virtual

### Notícias

A página utiliza uma estrutura de destaque onde uma notícia ocupa uma área maior, enquanto outras notícias são apresentadas em cards menores.

Cada card contém:

- Imagem
- Categoria
- Título da notícia
